# FMDB Pro data provenance

## FMDB Pro data sources

**Category:** first-party and licensed.

FMDB Pro is built on Sports Interactive's network of trained evaluators, the
research network behind Football Manager. Event data and physical metrics are
licensed from Hudl, which is Sports Interactive's exclusive provider for them.

Source: [Hudl and Sports Interactive partnership](https://www.hudl.com/blog/hudl-sports-interactive-partnership-fmdb-pro):
"Powered by a network of 1,600+ trained evaluators, it translates human-led
evaluation into comparable, actionable insight." and "Hudl becomes SI's
exclusive provider for event data and physical metrics for their new
professional football intelligence platform, FMDB Pro." Checked 2026-09-24.
