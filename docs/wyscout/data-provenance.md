# Wyscout data provenance

## Wyscout data sources

**Category:** first-party.

Hudl Wyscout collects its own event data from match video, at about 2,500 data
points per game. Hudl's pages describe the method differently: one says trained
analysts tag every match, and a later one says the data is generated
automatically from the footage. Both say the data comes from Wyscout itself, not
from a third party.

Sources, checked 2026-09-24:
[Wyscout data sourcing standard](https://www.hudl.com/blog/wyscout-video-data-sourcing-standard):
"Our data analysts are trained professionals who understand both the sport and
the technical aspects of data tagging... They analyze every match";
[Inside Wyscout](https://www.hudl.com/blog/inside-wyscout-scouts-ecnl): "Hudl
Wyscout generates 2,500 data points per game — automatically, from video. No
manual entry. No third party. The data comes directly from the footage."
