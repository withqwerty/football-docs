# Player Summaries

**Soccer Extended Player Summaries** provides match info and statistics for the past 10 matches in which a given player participated.

  ### Update Frequency

  300s Time To Live / Cache

> 📘 Retrieving Seasonal Statistics
>
> Learn how to use Player Summaries for a player's recent match statistics in our [Seasonal Statistics](https://developer.sportradar.com/soccer/docs/soccer-ig-seasonal-stats) integration scenario.
