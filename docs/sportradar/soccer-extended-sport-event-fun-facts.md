# Sport Event Fun Facts

**Soccer Extended Sport Event Fun Facts** provides noteworthy, human-readable, facts based on statistical information about a given match and its competing teams.

  ### Update Frequency

  300s Time To Live / Cache

> 📘 Enriching Match Coverage
>
> Learn how noteworthy match facts can enrich your coverage in our [Live Match Updates](https://developer.sportradar.com/soccer/docs/soccer-ig-live-match-retrieval) integration scenario.

***

## Data Points

### Sport Event - Fun Facts
  | Attribute   | Parent Element                   | Type   | Description                                                                                                                                                                                                                                                                      |
  | ----------- | -------------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | `statement` | `sport_event_fun_facts` - `fact` | String | Fun fact for a sport event<br />ex. `The most common result of matches between Chicago Fire and Real Salt Lake when Chicago Fire is playing at home is 0-0. 5 matches have ended with this result.` or `Real Salt Lake have scored at least one goal for 6 consecutive matches.` |
