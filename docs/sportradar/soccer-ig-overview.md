> 🚧 Note on Coverage Tiers
>
> Most concepts in this integration guide, especially around [**feed timings and data availability**](https://developer.sportradar.com/soccer/docs/soccer-ig-update-frequencies), apply primarily to Tier 1 competitions. We are actively working to expand the guide to reflect behavior across all coverage tiers.
>
> To learn more about tiers and coverage levels, visit the **[Data Coverage and Tiers](https://developer.sportradar.com/soccer/docs/soccer-ig-data-coverage-tiers)** page.

  ### Soccer API vs. Soccer Extended API

  All concepts covered in this guide apply to both the **[Soccer](https://developer.sportradar.com/soccer/reference/soccer-overview)** and **[Soccer Extended API](https://developer.sportradar.com/soccer/reference/soccer-extended-overview)** . If a feature or rule applies only to Soccer Extended, we note that explicitly.

  To learn more about the differences between the Soccer API and the Soccer Extended API, see our [**feature comparison guide**](https://developer.sportradar.com/soccer/docs/soccer-api-vs-soccer-extended-api).
