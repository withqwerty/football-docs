# Reep data provenance

## Reep data sources

**Category:** derived.

Reep does not collect match, event or player-performance data. It publishes
mappings between the IDs that other providers give to the same player, coach,
referee, team, competition, season, stage or match. The provider IDs come from
those providers; Reep's own contribution is the matching that links them to one
Reep ID.

Wikidata QIDs, and the external identifiers they carry, ship as a separate
overlay with lower confidence. They are a discovery aid, not a canonical bridge.
See `identity-and-ids.md`.

The public release is dedicated to the public domain under CC0 1.0. CC0 covers
only rights Reep holds and grants no rights in third-party source material.
