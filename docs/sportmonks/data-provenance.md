# SportMonks data provenance

## SportMonks data sources

**Category:** first-party and licensed.

SportMonks says it combines its own scouts with a network of external data
partners, and validates the data in its own processing system, both
automatically and by hand. It does not name the partners.

Source: [SportMonks football API](https://www.sportmonks.com/football-api/):
"We've built an online network of reliable data partners alongside our own
scouts, and we validate, manage and store everything in one data processing
system, automatically and manually." Checked 2026-09-24.
